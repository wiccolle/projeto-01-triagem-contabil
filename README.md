# Projeto 01: Triagem Administrativa de Escritório de Contabilidade

Este projeto estrutura um fluxo automatizado de triagem de atendimento inicial no balcão de um escritório de contabilidade, utilizando inteligência artificial para classificar demandas, responder a perguntas de apoio e definir o encaminhamento correto do cliente.
